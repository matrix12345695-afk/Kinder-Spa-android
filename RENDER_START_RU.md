# Kinder Spa: создание Worker в Render

[Открыть готовую форму Render](https://render.com/deploy?repo=https://github.com/matrix12345695-afk/Kinder-Spa-android/tree/kinder-render-inspection-20261029)

В форме должен быть только kinder-spa-telegram, Frankfurt, один 0.5c-512mb Worker
за согласованные $7/месяц. Выбери My Workspace. Новая база, диск, API или Cron
не создаются. Токен бота не требуется.

После создания процесс только проверяет структуру и права существующей
kinder-spa-db на чтение, затем ждёт. Он не запускает Telegram, не меняет данные
и не выполняет миграции. Running означает обследование, а не готовность бота.

Это отдельная ветка только для создания ресурса; не сливать её в основную ветку.
Программный код тот же, что в проверенном коммите c5aa4dc9. Автопубликация выключена.
После создания напиши «Создал»; проверку фактической версии и журнала выполнит Codex.
